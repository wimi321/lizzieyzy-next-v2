# 路线图

每个阶段都有退出条件。任务卡只写到当前阶段，下一阶段的卡在本阶段验收后再写。

| 阶段 | 粗估 | 退出条件 |
|---|---|---|
| P0 准备 | 2–3 周 | 骨架和门禁在三平台 CI 通过；功能清单由两位维护者定级；语料和 KataGo 录制就位；旧翻译转换完成 |
| P1 最小主线 | 4–6 周 | 打开 SGF → 棋盘 → 实时分析 → 胜率图 → 翻手，三平台可打包运行；维护者自己每天用它复盘 |
| P2 复盘 MVP | 2–3 个月 | 「2.0 预览版」公开发布，可与 Java 版同时安装 |
| P3 按需补齐 | 4–8 个月 | 大多数用户的日常操作不再需要 Java 版 |
| P4 切换 | — | 默认下载换成新版；Java 版只修严重 bug，3–6 个月后归档 |

**止损点**：P1 结束时，如果维护者自己都不愿意天天用，或者实时分析延迟、三平台打包解决不了，就停下来，回到 Java 版里原地重构。

## P2 待细化（P1 验收后写卡）

整盘分析（`analyzeTurns` + `priority`）与失误列表；SGF 编辑与变化树面板；SQLite 分析缓存；KataGo 分发组件（与 Java 版共用：构建、`katago-assets.json`、SHA-256、运行时兼容规则）；引擎向导与权重下载；野狐昵称抓谱；`LZ` 属性读写与 GIB 导入；中英文全界面；设置与 Java 配置导入；诊断包；自动更新与签名。

## P3 候选（按用户需求排序）

GTP 后端与人机 / 引擎对局；HumanSL 陪练；readboard 桥接；远程算力（WebSocket / SSH / 智子）；弈客；棋力评估；AI 解说；死活题；网页棋盘。

砍掉或降级的候选（由 P0-02 清单和下载数据决定）：Leela Zero 专用适配、多套历史主题、内嵌浏览器、下载量很低的 GPU 变体（改为按需组件）。
