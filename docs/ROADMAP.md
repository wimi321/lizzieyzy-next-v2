# 路线图

每个阶段都有退出条件。任务卡只写到当前阶段，下一阶段的卡在本阶段验收后再写。

| 阶段 | 粗估 | 退出条件 |
|---|---|---|
| P0 准备 | 2–3 周 | 骨架和门禁在三平台 CI 通过；功能清单由两位维护者定级；语料和 KataGo 录制就位；旧翻译转换完成 |
| P1 最小主线 | 4–6 周 | 打开 SGF → 棋盘 → 实时分析 → 胜率图 → 翻手，三平台可打包运行；维护者自己每天用它复盘 |
| P2 复盘 MVP | 2–3 个月 | 「2.0 预览版」公开发布，可与 Java 版同时安装 |
| P3 按需补齐 | 4–8 个月 | 大多数用户的日常操作不再需要 Java 版 |
| P4 切换 | — | 默认下载换成新版；Java 版只修严重 bug，3–6 个月后归档 |

**止损点**：P1 结束时，如果维护者自己都不愿意天天用，或者实时分析延迟、三平台打包解决不了，就停下来，回到 Java 版里原地重构。

## P2 待细化（P1 验收后写卡）
