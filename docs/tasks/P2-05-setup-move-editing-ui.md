## 目标

把 P2-03、P2-04 的命令接到界面上，P2 第 1 批「SGF 编辑」就此做完。入口照 Java 版放：菜单项、工具栏按钮、棋盘右键菜单和快捷键都在原位，原来置灰的点亮。样式由 Claude 定，标准见 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **起始局面设置。** 「棋局 → 起始局面设置」：
   - 起始局面设置模式（开关）；开着时，棋盘上的点击按所选工具放置黑子、放置白子、擦除棋子，不落子；
   - 清空全部设置子、黑先、白先；
   - 棋局已经有着手时，进入设置模式先问要不要「将当前盘面设为起始局面」，照 Java；菜单里的「将当前盘面设为起始局面...」同样先问；
   - 设置模式里棋盘上能看出当前是哪个工具，退出的办法明显。
2. **标记。** 顶部工具栏「标记工具」打开工具条：字母、数字、叉、方块、三角、橡皮擦、清除标记。选了工具后，棋盘上的点击放标记，不落子；再点一次工具或按 Esc 退出。
   - 棋盘画出当前手的标记（`DocumentView.markup`），棋子上和空点上都看得清；导入的棋谱里的标记也画。
3. **交换落子顺序。** 顶部工具栏的按钮。
4. **指定颜色落子。** 「编辑 → 添加黑子、添加白子、交替落子」和顶部工具栏的三个按钮：前两个模式下点击落指定颜色，交替落子是平常的落子。当前模式在按钮上看得出。
5. **插入黑子、插入白子。** 「编辑」菜单，以及棋盘右键单击空点。
6. **棋盘右键菜单**，照 Java 的 `RightClickMenu`、`RightClickMenu2`：
   - 空点：插入黑子、插入白子、回退一手；
   - 候选点：添加为分支（把这个候选点的变化加进棋谱）；
   - 棋子：跳到此步、移动、反色、删除、回看。「移动」先选子、再点目标点。
7. **试下。** 底部工具栏「试下」：开始后按钮变成「恢复」，窗口标题显示「试下中...」，点「恢复」回到原棋谱。试下期间不该用的入口（保存等）照 P2-04 的后端行为置灰或提示。

## 不做

- 自由涂鸦、强制计算区域等其他工具：后面的批次。

## 验收标准

1. 每一项都有 Playwright 用例：从菜单、工具栏、右键菜单或快捷键触发，核对发给后端的命令和参数；设置模式、标记工具、右键菜单、试下各有一张截图基线。
2. Vitest 覆盖：设置模式和标记模式下点击的去向；右键菜单按点击位置（空点、候选点、棋子）给出的条目；标记的绘制位置。
3. `scripts/verify.sh` 通过，截图基线重新生成。
