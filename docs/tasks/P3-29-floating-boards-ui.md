## 目标

P3-27 的浮动棋盘窗口的前端，以及主窗口里的入口。行为要点见 P3-27 和本卡；样式标准照 ROADMAP 2026-11-11 的记录。

## 要做

1. **浮动窗口的页面**：前端按 URL 的 `window` 参数，`float-main` / `float-sub` 时只渲染浮动棋盘，不加载主窗口。
   - 浮动主棋盘：一块棋盘铺满窗口，显示和主棋盘一样的分析。
     - 交互：左键落子、滚轮翻手、悬停候选点看变化、Alt+拖动圈选、空格暂停分析、方向键和 Home/End 翻手。不做右键菜单。
     - 鼠标进入窗口时，左上角出现三个小按钮：关闭、置顶、锁定。
     - 窗口内按住拖动移动窗口；靠边缘拖动缩放，保持正方形；锁定后两者都不行。
   - 浮动小棋盘：一块小棋盘，显示和主窗口小棋盘一样的内容；滚轮逐手看变化；同样的三个按钮、拖动和缩放。
   - 两个窗口订阅同样的事件，和主窗口同步；对局中照主棋盘的规则限制。
2. **入口**
   - 显示 → 面板：
     - 浮动主棋盘 (Alt+Q)：主棋盘浮动出去，主窗口不再画主棋盘；
     - 浮动主棋盘(保留原棋盘)：浮动出去，主窗口保留主棋盘；
     - 浮动小棋盘 (Alt+A)：小棋盘浮动出去，主窗口不再画小棋盘。
     三项都是勾选项，按真实状态打勾；点已勾选的项就关掉对应的浮动窗口。
   - 显示 → 浮动棋盘模式（预设，调 `set_floating_layout`）：
     - 浮动双棋盘 (Alt+7)：主棋盘和小棋盘都浮动出去，主窗口只放信息面板；
     - 浮动主棋盘：主棋盘浮动出去，小棋盘留在主窗口；
     - 浮动小棋盘：只浮动小棋盘；
     - 额外浮动棋盘：两块都浮动出去，主窗口保持完整。
   - 可视化面板设置和自定义布局（P3-28）加上浮动主棋盘、浮动小棋盘两项；勾浮动主棋盘时两个放大变灰，勾浮动小棋盘时「显示小棋盘」变灰；自定义布局存这两个窗口的开关和位置，套用时关掉布局里没有的浮动窗口。
3. **主棋盘浮动出去时主窗口的布局**（照 Java `gui/LizzieFrame.java` 6927–7095）：左栏宽 = 可用宽 / 8 × 位置比例，从上到下是信息、胜率图、评论；右栏是分支面板和选点列表，小棋盘贴底（小棋盘浮动出去时不画）；左栏三项都关时右栏占满，反之亦然。浮动双棋盘时主窗口宽改为 (高 − 工具栏) × 65%（走 `fit_main_window`）。
4. 关掉浮动主棋盘（按钮或系统方式）只是收回棋盘，不重置布局。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后调用对应的命令，界面随 `FloatingBoardsChanged` 和设置变化。
2. 浮动棋盘页面的组件测试：按钮、锁定后不能拖、正方形缩放、滚轮翻手。
3. Playwright 截图基线：浮动主棋盘页面（鼠标在窗口里，三个按钮可见）、主棋盘浮动出去后的主窗口、可视化面板设置里的两项浮动开关。
4. 每个 Playwright 测试最多点开两层菜单，本地 1.3 秒以内。
5. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
