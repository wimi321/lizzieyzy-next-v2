## 目标

维护者 2026-11-03：「界面还不是 1 比 1 还原，还是严格还原吧」。

P1-20 只照 LizzieYzy Next 的布局方向重做，外观是新设计的。从这张卡起，主窗口严格照 Java 版还原：位置、尺寸、颜色、字体、图标、文字都以 Java 版为准。界面由 Claude 做。

**参照物**是维护者电脑上的 LizzieYzy Next next-2026-10-21.1，用维护者自己的设置（2026-11-03 截图）：
- 浅色界面：工具栏底色 `#f4f5f7`，按钮白底；
- 棋盘风格 japanese，主题 default；
- 打开的面板：提子、胜率图、评论、变化树、小棋盘、状态栏；
- 选点列表不显示：维护者 2026-11-01 说过不要。

**统一规则：**
- 已实现的功能：控件照 Java 版放，照 Java 版做。
- 已定级、还没做的功能：控件照样放在原位，置灰。Java 版对不可用的按钮也是置灰。做好一个点亮一个。
- 已砍掉的功能（跑谱贡献等）：不放。

Java 版的图标和贴图（`src/main/resources/assets`）同为 GPL-3.0，直接复制使用。

## 要做

1. **窗口标题**照 `MainWindowTitle`：「LizzieYzy Next 2 - [黑胜率 目差 计算量] 引擎名 速度 搜索/秒 - [黑] 名字 vs [白] 名字 (结果:…) - 文件名」。缺的部分连同分隔符一起省掉。
2. **菜单栏**照 `WindowMenuStrip`：
   - 浅色底，菜单名加粗；
   - 右侧是当前引擎「[1]: 引擎名 ⌄」，点开是引擎菜单；
   - 再往右是「AI 陪练」「AI 解说」两个按钮。它们是 P3，先置灰。
3. **顶部工具栏**照 `TopHeaderPanel` 和 `Menu` 里的顺序：
   - 新建、打开、保存三个图标；
   - 野狐棋谱、腾讯棋谱、棋力评估、一键设置、闪电分析；
   - 搜索功能；
   - 鹰眼、落子评价标记、交换落子顺序、设为主分支、返回主分支、控制面板、标记工具；
   - 黑、白、黑白交替；
   - 强制计算区域的五个按钮；
   - 新对局、暂停；
   - 贴目；
   - 激进度、广度；
   - 选点：黑、白；
   - 规则、死活、参数、棋盘、存档。

   一行放不下时换行，1429 宽时「死活 参数 棋盘 存档」换到第二行。
4. **底部工具栏**照 `BottomToolbar` 的默认内容：
   - 暂停分析、自动分析、远程算力、更新官方权重、Kata形势；
   - |< << < > >> >|、手数输入框、跳转、自动播放；
   - 设为主分支、手数、坐标、清空棋盘、删除、更多。
5. **主面板区域**照 `InFrameLayout` 的默认横屏布局计算（`BoardPositionProportion` = 4，选点列表关）：
   - 左栏：提子框、胜率条、胜率图、评论/问题手、状态栏；
   - 中间：棋盘正方形；
   - 右栏：变化树在上，小棋盘在下；
   - 空出的地方铺 `background.jpg`；
   - 窗口缩放时按同一公式重算。
6. **现有内容搬进对应区域。** 各区域内部的严格还原另有三张卡：P1-41 棋盘，P1-42 左栏，P1-43 右栏。
7. **去掉新版自己加的东西：** 顶部的新式工具条、主题切换。它们的功能回到 Java 版的位置：
   - 暂停分析、自动分析、翻手：底部工具栏；
   - 分析速度：窗口标题；
   - 引擎状态：状态栏。

   死活、棋盘同步、性能优化进行中的提示在 Java 版没有对应位置，只在进行时显示在菜单栏右端。
8. **单步分析限制停下时**，照 Java 版弹非模态提示框，代替 P1-39 的浮条：
   - 标题「计算已停止」；
   - 两行说明；
   - 「不再提示」勾选，本次运行内有效。

## 不做

- 各区域内部的绘制（棋盘、胜率图、变化树、小棋盘）：见 P1-41 至 P1-43。
- 对话框的严格还原：主窗口完成后另开卡。
- 置灰按钮背后的功能：各自的功能卡里做。

## 验收标准

1. 同样的窗口大小下，与 Java 版截图逐区域对照：
   - 各区域的位置、尺寸误差不超过 2 px；
   - 底色、按钮样式、字号一致。
2. Vitest 覆盖布局公式：1429×969 和 1920×1080 两种窗口，结果与 Java 公式一致。
3. Playwright：
   - 工具栏按钮的启用、置灰正确；
   - 已实现的按钮能用，原有 E2E 全部通过；
   - 截图基线重新生成。
