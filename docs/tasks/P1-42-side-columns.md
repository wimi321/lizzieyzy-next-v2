## 要做

1. **提子框：**
   - 黑白棋子图，中间是规则名，例如「中国规则」；
   - 轮到谁走：「● 黑走」；有棋力评估结果时，两边显示吻合度；
   - 「提子 n　贴目 x　提子 n」。
2. **胜率条：**
   - 「黑 x%　手数　白 x%」和黑白条；
   - 下面一行：谁领先多少目，上一手的胜率和目差变化。
3. **胜率图：**
   - 纵轴 100 / 50% / 0，横轴手数，虚线网格；
   - 蓝色胜率线、紫色目差线，图例「黑方胜率」「目差」；
   - 当前手的标记和数值；
   - 点击和拖动跳转，照旧。
4. **评论 / 问题手面板：**
   - 两个标签，顺序照 Java 版：评论、问题手；右侧显示评估状态；
   - 评论区：当前手的分析摘要（哪方、胜率、领先、引擎名和计算量、贴目），下面是棋谱里的评论；
   - 问题手列表照旧。
5. **变化树：**
   - 主线和分支的连线；
   - 节点圆点区分：已分析、当前手、有评论；
   - 手数刻度，自动滚动到当前手，点击跳转。
6. **小棋盘：**
   - 平时显示最佳点的变化图，鼠标悬停候选点时显示该点的变化图；
   - 棋子上的数字，画法与主棋盘的变化图一致。
7. **接上 P1-44 的数据：**
   - 窗口标题里的文件名；
   - 菜单栏、标题和状态行里的引擎显示名（目录里的三档按界面语言翻译）；
   - 打开失败时给出提示。
