## 目标

把 P2-06 保存的显示设置接到「显示」菜单和界面上，P2 第 2 批的第一部分就此做完。菜单项照 Java 版的位置和勾选状态，改了立即生效并保存，重启后还在。样式标准见 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **坐标。** 「显示 → 坐标」开关棋盘四周的坐标，关掉后棋盘随之放大。
2. **手数。** 「显示 → 手数」各项：不显示、最后 1/5/10 手、全部、最后 N 手（对话框输入 N）；分支内从 1 开始、分支内接着主线编号；分支里显示全部手数。手数画在棋子上，用和子色相反的颜色；最后一手照旧有标记。变化图预览里的手数照现在的样子。
3. **落子评价标记。** 「显示 → 落子评价标记」：不显示、最后一手、最后 N 手、全部。有评价的着手在棋子上画出评价颜色的标记，颜色和分支面板里的点一致。
4. **选点信息。** 胜率、计算量、目数三行各自开关；目数显示为与最佳点之差；候选点右上角的序号；总是显示黑方胜率；鼠标悬停显示变化图。
5. **下一手提示。** 棋谱里当前局面有下一手时，按「不显示 / 简单 / 带胜率目差」在棋盘上提示；带数值的提示只在那一手的计算量不低于阈值时显示数值。阈值由菜单项打开对话框设置。
6. **面板与工具栏。** 「显示 → 面板」里胜率图、评论/问题手、分支面板、信息面板、状态栏、小棋盘，以及顶部、底部工具栏，各自显示或隐藏。隐藏后空出的地方照 Java 的布局分给相邻面板，棋盘随窗口重新排布。
7. **胜率图设置。** 只画胜率、只画目差、两者都画；单曲线时面积填充；柱状失误条。
8. **目数显示。** 「KataGo相关设置 → 目数显示」带贴目、不带贴目，影响候选点、信息面板和胜率图里的目数。
9. **主界面设置。** 棋盘下方显示黑白名字；「新的棋盘」「覆盖文件」两个确认对话框的开关，关掉后对应操作不再询问。
10. 这一批不做的「显示」菜单项继续置灰。

## 验收标准

1. 每个菜单项：勾选状态和保存的设置一致，点了以后界面立即变化、设置写回后端，有单元测试或 Playwright 测试。
2. Playwright 截图基线：关坐标、全部手数、落子评价标记、只画目差且带失误条、隐藏胜率图和评论面板后的布局、下一手提示。
3. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过；`App.tsx` 先拆出去一部分，给这一批留出余量。
