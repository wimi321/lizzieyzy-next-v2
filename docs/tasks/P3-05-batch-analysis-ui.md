## 目标

把 P3-04 的后端接到「分析」菜单上。入口照 Java 版放；样式标准照 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **分析 → 批量分析（Ctrl+O）。**
   - 先多选棋谱（SGF、GIB），再打开批量分析对话框。对话框里可以设：
     - 计算量：沿用整盘精析的预设；
     - 只分析一段手数，或分析所有分支；
     - 输出位置：原棋谱旁边，或另选的文件夹。
   - 当前棋谱有未保存的修改时，开始前先确认，与打开文件一样。
2. **分析 → 批量精析。** 同一个对话框，计算量和「总是覆盖」取自精析设置。
3. **分析 → 批量分析进度表。** 一个窗口，表格列出序号、文件名、状态或进度、输出文件，按钮有：增加棋谱、删除、上移、下移、优先、清空、开始 / 结束、暂停 / 继续。完成的项目可以点开输出文件。
4. **分析 → 停止自动（批量）分析。** 批量运行时也能停止它。
5. **精析。** 这几项都用精析设置里的计算量：
   - 整盘速览（闪电）；
   - 局部精析：先弹出开始手数和结束手数，两个都可以留空；
   - 全部分支精析。
6. **分析 → 精析设置。** 单步计算量、总是覆盖已有分析结果，按钮有「确定」和「确定并重新计算」。后者用新设置把最近一次精析再跑一遍。
7. 批量运行时，菜单栏右侧的托盘里显示进度（第几盘、共几盘、这一盘的进度），点了打开进度表。被批量挡住的操作，给出说明。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后调用对应的命令，界面随之变化。批量的进度、失败项、暂停、停止各有测试。
2. Playwright 截图基线：批量分析对话框、进度表（含完成、运行中、失败、等待四种状态）、精析设置。
3. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
