## 目标

把 P1-23、P1-24、P1-25 的结果做成维护者日常复盘用的界面，观感和操作照 LizzieYzy Next。界面由 Claude 做。

## 要做

- 自动分析：
  - "分析"菜单和工具栏都能开始；
  - 选择计算量预设（快速 / 标准 / 深入 / 专业，或自定义）；
  - 进行中显示进度，可以暂停、继续、取消；
  - 胜率图随进度填满。
- 问题手：
  - 侧栏有"问题手"面板，可以按黑白筛选；
  - 每项显示手数、坐标、胜率损失、目差损失，按等级配色；
  - 点击跳转；
  - 胜率图下方显示失误条。
- 棋力评估：
  - "分析"菜单打开评估窗口，显示双方的段位估计、吻合度、平均损失、分阶段数据；
  - 左栏双方信息处显示吻合度；
  - 数据不足时给出说明。
- 所有文字走 i18n，中英文都要有。

## 验收标准

1. Vitest 和 Playwright（mock 后端）：
   - 自动分析的开始、进度、暂停、继续、取消；
   - 问题手的筛选和跳转；
   - 评估窗口的各种数据状态。
2. 维护者用自己的野狐棋谱在 macOS 上实测：抓谱、自动分析、看问题手、看棋力评估，一条龙走通。
3. 截图基线在 Linux 上重新生成，`scripts/verify.sh --e2e` 通过。
