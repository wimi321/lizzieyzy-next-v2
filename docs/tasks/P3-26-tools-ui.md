## 目标

把 P3-24 的后端接上，并补齐几样纯界面的工具。入口照 Java 版放（Java 的入口和行为要点已写在本卡里）；样式标准照 ROADMAP 2026-11-11 的记录。

## 要做

1. **搜索功能**
   - 入口：顶栏「搜索功能」按钮，Ctrl/⌘K。焦点在文本框里或者有模态窗口时，快捷键不生效。
   - 窗口：一个输入框；输入为空时可以按分类浏览。分类照 Java 的 6 类：棋谱与文件、分析、对局、引擎与加速、同步、界面与系统。
   - 结果：每行显示标题和菜单路径；选中的行再显示快捷键和不可用的原因。
   - 键盘：↑↓ 选择，Enter 执行，Esc 关闭。正在用输入法拼字时，Enter 交给输入法。
   - 目录用现有的菜单定义和各处的菜单绑定生成：可执行的条目直接执行，子菜单展开到对应的菜单项，不可用的条目变灰。
   - 匹配：当前界面语言加英文；排序依次是完全相等、整句包含、分词全部包含。不做拼音缩写和拼写纠错。
   - 不改用户的工具栏设置。Java 定位按钮时会把用户关掉的工具栏分组强制打开，不照抄。
2. **自由涂鸦**
   - 入口：顶栏涂鸦按钮，以及控制面板里的「涂鸦」。
   - 一层透明覆盖层，盖住棋盘区域。
     - 蓝、绿、红三色，线宽固定；
     - 撤销一笔、全部清除；
     - Esc 或 ✕ 关闭。
   - 只认左键；右键不画，也不会把两笔连起来。
   - 不保存：关闭即丢。只记住上次用的颜色（`painting_color`）。
   - 窗口缩放时，覆盖层跟着棋盘区域走。
3. **独立棋局控制面板**
   - 入口：顶栏按钮，「显示 → 面板 → 独立棋局控制面板」（勾选项，实时反映是否显示）。
   - 一个可拖动、可缩放的浮动面板，8 个大按钮：
     - `|<` `>|`；
     - `<<` `>>`：一次 5 手，照 Java；
     - `<` `>`；
     - 返回主分支；
     - 涂鸦。
   - 位置和大小保存在 `control_panel_bounds`。
4. **存档与读档**
   - 入口：「文件 → 存档与读档」、顶栏「存档」按钮。
   - 打开时盖住列表和变化树所在的区域，照 Java 的布局：
     - 每个槽一张缩略棋盘，按后端给的局面快照画，写着编号、名称、时间和手数；
     - 每个槽有读取、覆盖、重命名、删除；覆盖和删除前要确认；
     - 最后一格是「新建存档」；
     - 自动存档单独一格，只能读取。
   - 顶部：「自动存档」和「启动时恢复」两个开关、「全部删除」（要确认）、「关闭」。
   - 损坏的槽显示「已损坏」，只能删除。
5. **自动播放**
   - 入口：「显示 → 自动播放 (Ctrl+A)」、底栏「自动播放」按钮。
   - 一个小窗口设置间隔（秒，可以有小数），确定后开始。
   - 主棋盘每隔一个间隔前进一手，走到当前分支的最后一手就自动停。播放中用户手动走了棋，这一拍跳过。
   - 播放时底栏按钮呈按下状态，再点一次停止。
   - Java 的「每步下引擎首选」不做，人机续弈已经覆盖。副棋盘和变化图的自动回放不在这一批。
6. **e2e 的灰按钮清单**：`frame.spec.ts` 把「按状态变灰」和「尚未实现」分成两组断言。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后调用对应的命令，界面随返回的状态和事件变化。
2. Playwright 截图基线：
   - 搜索窗口：浏览和有结果两种状态；
   - 涂鸦中的棋盘；
   - 控制面板；
   - 存档面板：有几个槽、一个已损坏；
   - 自动播放的设置窗口。
3. 自动播放的计时用假时钟测，不等真实时间。
4. 每个 Playwright 测试最多点开两层菜单，本地 1.3 秒以内。
5. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
