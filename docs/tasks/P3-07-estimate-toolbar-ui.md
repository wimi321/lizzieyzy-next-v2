## 目标

把 P3-06 的后端接到界面上。入口照 Java 版放；样式标准照 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **显示 → KataGo相关设置 → Kata形势显示。**
   - 关闭、隐藏、显示在大棋盘上、显示在小棋盘上、显示在所有棋盘上。
   - 五种画法，大棋盘和小棋盘都照所选的画。
   - 「在纯网络中显示」的五种画法。
   - 记忆评估显示状态。
   - 按选点显示评估：鼠标悬停在某个选点上时，形势改为显示这个选点下完后的 ownership。
   - 使用快捷键：照 Java 用大键盘的「.」开关形势。
   - 底部工具栏的「Kata形势」按钮开关形势。
2. **分析 → 纯网络（H）和策略网络。**
   - 纯网络：显示神经网络的原始输出，包括 policy 热点、胜率和目差，形势按「在纯网络中显示」的画法画。再按一次回到原来的分析。
   - 策略网络：在实时分析的大棋盘上叠加 policy 热点。
3. **显示 → 小棋盘设置。**
   - 热点图：第一感热点图（policy）、计算后热点图（各选点的计算量占比）、不显示。
   - 变化图 / 仅棋盘棋子。
4. **显示 → 工具栏。**
   - 顶部工具栏：独立显示、合并在菜单栏上、不显示；自动换行（仅独立显示时有效）。
   - 顶部工具栏的「自定义内容」照 Java 分组，且 PDA 和广度（WRN）可以分别隐藏（Java 版 #709）。
   - 底部工具栏的「自定义内容」。
   - 选择都保存，重启后照旧。
5. 附加数据按需打开：只有在需要显示 policy 或按选点 ownership 时，才打开 P3-06 的 `set_analysis_extras`。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后保存设置或调用命令，界面随之变化。
2. Playwright 截图基线：
   - 五种形势画法（可以合成一张）；
   - 纯网络的 policy 热点；
   - 小棋盘的第一感热点图；
   - 一个自定义过的顶部工具栏，和合并在菜单栏上的顶部工具栏。
3. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
