## 目标

把 P3-01 的后端和 P3-02 的译文接到界面上。入口照 Java 版放；样式标准照 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **文件菜单。**
   - 复制棋谱到剪贴板、从剪贴板粘贴棋谱。粘贴时有未保存的修改，先确认，与打开文件一样。
   - 更多保存：保存纯净棋谱、保存纯净棋谱（带评论）、保存纯净分支、保存主棋盘截图、保存小棋盘截图、保存胜率图截图。
   - 复制主棋盘到剪贴板、复制小棋盘到剪贴板。
   - 快捷键照 Java；焦点在输入框里时，复制粘贴的快捷键留给输入框。
2. **截图。** 棋盘按当前所见渲染成 PNG，包括候选点和标记；胜率图从当前所见渲染。保存对话框的默认文件名用棋谱名加手数。
3. **编辑菜单。** 向右旋转、向左旋转、水平翻转、垂直翻转，快捷键照 Java。
4. **显示和设置。**
   - 显示 → 总在最前。
   - 设置 → 界面字号：小、中、大、其他。
   - 设置 → 播放落子声：落子和翻手时播放。声音文件随程序发布，在汇报里写明来源和许可证。
   - 文件 → 加载棋谱中的贴目：勾选项，用 P2-11 已有的 `read_komi`。
5. **设置 → 语言。** 繁體中文、日本語、한국어、ไทย 四项可选，选了立即切换并保存。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后调用对应的命令，界面随之变化；粘贴失败、图片保存失败时都给出提示。
2. Playwright 截图基线：「更多保存」子菜单、日语界面的主窗口（裁剪）、大号字体的主窗口（裁剪）。
3. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
