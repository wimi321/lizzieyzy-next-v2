## 目标

把 P1-19 和 P1-21 的后端接到 P1-20 的新布局上。界面由 Claude 做。

## 要做

- 野狐棋谱窗口，行为照 Java 版：
  - 查询方式可选昵称或 UID，输入后搜索；
  - 显示当前账号，列出棋谱，可以翻页，没有更多时提示；
  - 双击或点打开，打开这盘棋；
  - 打开后这个窗口可选：最小化、关闭、不动；
  - 显示近期搜索记录，点一下直接搜，可以清空；
  - 出错时给出可读的提示：没有这个账号、UID 格式不对、网络错误。
- 工具栏的"野狐棋谱"按钮和菜单项打开这个窗口。
- 左栏接上对局信息。
- 右栏接上变化树，点节点跳转。
- 鼠标移到候选点或表格行上时，棋盘按序号显示这条变化（含提子）；移开后恢复。

## 验收标准

1. Vitest 和 Playwright（mock 后端）：
   - 搜索、翻页、打开、出错提示、近期搜索；
   - 变化树跳转、变化预览显示和恢复。
2. 维护者用自己的野狐昵称在 macOS 上实测：能列出最近的棋谱，打开后能分析。
3. 截图基线在 Linux 上重新生成，`scripts/verify.sh --e2e` 通过。
