## 目标

把 P3-23 的后端接到界面上。入口照 Java 版放（Java 的入口和行为要点已写在 P3-23 和本卡里）；样式标准照 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **选点限制**
   - 顶栏五个按钮：
     - 「设置强制计算区域」和「设置强制不计算区域」：点一下进入一次性圈选，再点退出，点另一个就切换种类；
     - 「允许选点选项」和「排除选点选项」：弹出深度菜单，选项为「仅第一手 / 自定义 N / 整个搜索」；
     - 「清除强制区域」。
   - 棋盘上：
     - Alt+拖动直接圈「计算区域」；Alt+单击清除；
     - 拖动时显示半透明矩形，计算区域蓝色、不计算区域红色；
     - 松开后把矩形内的交叉点交给 Rust，和已有的点取并集。矩形在两个方向上都要跨过一条线才算，单击不算。
   - 受限的点：每点画一格半透明方块。
   - 状态栏右侧的托盘里显示「选点限制」小标签，写明种类和点数，点它可以清除，这样限制一直看得见。
   - 右键空点：只分析此点 / 增加分析此点 / 去除分析此点 / 不分析此点 / 清除分析限制，按当前状态显示或隐藏。
   - 对局中这些入口变灰。
2. **引擎参数**
   - 入口：「设置 → 引擎参数」、顶栏「参数」按钮、Alt+D。
   - 窗口：PDA、WRN、rootPolicyTemperature 三项，有「恢复默认」。每项写一句说明，参考 Java 的说法。
   - 顶栏原本灰着的 PDA、WRN 输入框改成可用，和窗口里的值同步，改了立即生效。
3. **终局点目**
   - 入口：「棋局 → 终局点目 (Ctrl+Q)」，是勾选项。
   - 棋盘上：每个点画归属小方块（黑或白），无目点和中立点画红点。左键点子翻转整块死活，点空点切换无目点。
   - 结果窗口：非模态，放在棋盘旁边。
     - 规则切换：数子 / 数目；
     - 黑白双方的算式，用后端给的明细排版；
     - 结果；
     - 「确定」写入对局结果并退出；「取消」退出。
   - 点目时其他会改棋谱的入口变灰，或者让点目自动退出（照后端的行为）。
4. **自动补完征子**
   - 「棋局 → 自动补完征子」。
   - 结果用一行提示说明：征死、逃出，或者「这里没有在进行的征子」。追加的着手可以一次撤销。
5. **只需接线的灰按钮**：顶栏「规则」打开现有的引擎规则窗口；底栏「更新官方权重」打开引擎工具的「权重」页。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后调用对应的命令，界面随返回的状态和事件变化。
2. Playwright 截图基线：
   - 圈选中的矩形和受限点；
   - 深度菜单；
   - 引擎参数窗口；
   - 点目中的棋盘和结果窗口。
3. 每个 Playwright 测试最多点开两层菜单，本地 1.3 秒以内（Linux CI 的上限是 5 秒）。
4. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
