## 目标

把 P2-14 的后端接到界面上，P2 的界面就此做完。入口照 Java 版放；样式标准见 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **帮助 → 检查更新。** 打开一个对话框：正在检查、已是最新、有新版本（版本号、日期、发布说明）。有新版本时可以下载，有进度和取消；下载好后「安装并重启」（或在 macOS、Linux 上「打开所在位置」，照后端给出的方式）。签名校验失败时说明原因，不安装。「启动时自动检查」的开关放在对话框里，也放进综合设置。启动时自动检查到新版本，只在菜单栏右侧的托盘里放一个提示，点了打开这个对话框，不弹窗打断。
2. **帮助 → 诊断与日志。** 显示日志所在位置和当前级别；「开始完整日志」（显示剩余时间）和「停止完整日志」；「导出诊断包」，完成后可以打开所在文件夹，并说明包里有什么、没有什么（不含棋谱）。菜单里的「停止完整日志」只在完整日志开着时可用。
3. **设置 → 语言。** 跟随系统 / 简体中文 / English 三项勾选，选了立即切换界面语言并保存；其余 Java 语言照旧置灰。
4. 菜单里这一批不做的项继续置灰。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后调用对应命令、界面随之变化；更新的「已是最新」「有新版本」「下载中取消」「签名不对」，各有测试。
2. Playwright 截图基线：检查更新（有新版本）、诊断与日志、英文界面的主窗口。
3. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
