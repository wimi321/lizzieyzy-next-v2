## 目标

把 P3-09 和 P3-10 的后端接到界面上。入口照 Java 版放；样式标准照 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **棋局 → 新对局 → 人机对局（N）。** 一个对话框，合并 Java 的两种人机对局。
   - 基本项：
     - 对手：KataGo 或某个 GTP 引擎；
     - 执黑、执白；
     - 当前局面续弈：勾选后让子不可用；
     - 让子、贴目、规则；
     - 限制我的用时：保留时间、读秒秒数和次数。
   - AI 用时：
     - KataGo：每手秒数、计算量、纯网络；
     - GTP 引擎：五种时间设置。
   - 更多：认输规则、随机开局、对局时后台计算、自动保存、对弈模式。对弈模式下隐藏胜率、选点和变化，可分别为黑方、白方显示选点。
   - 打开时回显上次的设置；后端拒绝时显示原因。
2. **对局中。**
   - 顶部工具栏的「暂停」「结束对局」「认输」，以及棋局菜单的「终止人机对局」「修改AI用时」，在对局中可用。
   - 人的时钟显示在 Java 的位置：隐藏胜率图时显示在菜单栏一侧。读秒最后 10 秒醒目提示。
   - AI 思考中有状态提示。
   - 悔棋：用现有的后退键和按钮，对局中改为调用 `take_back`。
   - 对局结束时，用非模态提示显示结果和原因，以及保存的位置。
   - 对弈模式下，胜率图、选点和变化照设置隐藏。
3. **棋局 → 人机续弈（Enter）、让AI落子最佳一手（逗号）。**
   - 人机续弈：菜单里有「AI 执黑」「AI 执白」；按 Enter 时，AI 执轮到走的一方。
   - 逗号：鼠标悬停在某个变化上时，按显示的长度落下这串着法；否则落首选点。
4. **棋局 → 新对局 → 引擎对局（Alt+E）。**
   - 两列：引擎 1 和引擎 2，各自的引擎和用时或时间设置，KataGo 方还有认输规则和开局 WRN / PDA。
   - 全局：盘数、交换黑白、贴目、让子、规则、最大手数、开局 SGF（可多选，按顺序或随机）、随机开局、从当前局面开始、自动保存。
   - 比赛中：
     - 窗口标题显示 Java 那样的「胜:负 A VS B 胜率 x% 2σ…」；
     - 有一块比分面板：各方总胜、执黑胜、执白胜，不计分的盘数，Elo 和区间，按开局的统计；
     - 棋局菜单可以暂停、继续、终止、修改盘数；
     - 「干预引擎对局」可以立即落子、手动认输；
     - 可以修改双方的 WRN / PDA。
5. **设置 → 引擎：GTP 引擎。**
   - 和 KataGo 引擎分开的一组：增、改、删、测试。测试会显示 name、version，或者失败的原因。
   - 字段：名称、程序、参数、工作目录、启动后发送的命令。
6. **显示 → 面板 → Gtp控制台。**
   - 显示选中的 GTP 引擎的收发记录：命令和回复用不同的颜色，错误用红色。
   - 输入框、发送、命令列表（来自 `list_commands`）、清空。对局中被拒绝的命令显示原因。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后保存设置或调用命令，界面随之变化。
2. Playwright 截图基线：
   - 人机对局对话框；
   - 对局中的时钟和工具栏；
   - 对局结果提示；
   - 引擎对局对话框；
   - 比分面板；
   - GTP 引擎设置；
   - Gtp控制台。
3. 每个 Playwright 测试最多点开两层菜单，本地 1.3 秒以内（Linux CI 的 5 秒上限）。
4. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
