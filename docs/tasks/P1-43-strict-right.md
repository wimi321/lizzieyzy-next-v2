## 目标

右栏照 Java 版严格还原。参照物和统一规则见 P1-40。界面由 Claude 做。选点列表不做。

## 要做

1. **变化树**照 `VariationTree`：
   - 底色、主线和分支的连线；
   - 节点圆点的颜色：已分析、当前手、有评论；
   - 根节点标记；
   - 手数刻度；
   - 自动滚动到当前手；
   - 点击跳转。
2. **小棋盘**照 `SubBoardRenderer`：
   - 平时显示最佳点的变化图；
   - 鼠标悬停候选点时，显示该点的变化图；
   - 棋子上的数字；
   - 右下角的角标；
   - 棋盘贴图。

## 验收标准

1. 与 Java 版截图对照，看不出差别：
   - 开局；
   - 中盘有分支的棋谱。
2. Vitest、Playwright 通过，截图基线重新生成。
