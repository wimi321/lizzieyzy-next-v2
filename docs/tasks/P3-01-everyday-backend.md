## 目标

P3 第 1 批：Java 用户每天会用、做起来不难的功能的后端。Java 参考在 `../lizzieyzy-next`，只学行为：`gui/Menu.java` 的「文件」菜单（复制棋谱到剪贴板、从剪贴板粘贴棋谱、更多保存）和「编辑」菜单的旋转翻转，`LizzieFrame` 的 `copySgf`、`pasteSgf`、`saveRawFile*`、`saveCurrentBranch`、`saveMainBoardPicture`、`saveMainBoardToClipboard`、`saveImage`、`toggleAlwaysOntop`、`setFrameFontSize`，`Board.SpinAndMirror`，配置项 `play-sound`。

## 要做

1. **剪贴板棋谱。**
   - 复制：把当前棋谱序列化成 SGF 文本，写进系统剪贴板。带不带分析数据照 Java。
   - 粘贴：读系统剪贴板的文字，按打开文件的同一条路径识别（SGF，以及已支持的其他格式），作为一盘新的、未保存的棋谱打开。打开后的行为与打开文件一致（引擎分析、自动胜率曲线等）；有未保存修改时的确认由界面负责。
   - 剪贴板没有文字或解析失败时，返回类型化错误，当前棋谱不动。
   - Java 版 issue #627「无法分析从剪贴板粘贴的局面」：粘贴进来的局面必须能分析，写测试。
   - 剪贴板放在 Rust 里读写（例如官方 `tauri-plugin-clipboard-manager`），不依赖 WebView 的 `navigator.clipboard`，它在各平台的权限行为不一样。app-core 里通过一个可替换的接口使用剪贴板，测试不碰真正的系统剪贴板。
2. **纯净棋谱（文件 → 更多保存）。**
   - 保存纯净棋谱：去掉分析数据和评论，具体去掉哪些属性照 Java；「带评论」的版本保留评论。
   - 保存纯净分支：只保存当前节点所在的那条线，止于当前节点还是该分支末尾照 Java。
   - 写到界面给的路径，原子写入。不改变当前文档的路径、标题和已保存状态。
3. **图片。** 棋盘和胜率图由界面渲染成 PNG 字节，后端提供两个命令：
   - 把 PNG 写到界面给的路径：校验是 PNG，设大小上限（例如 32 MiB），原子写入；
   - 把 PNG 作为图片放进系统剪贴板。
4. **旋转和翻转（编辑 → 向右旋转、向左旋转、水平翻转、垂直翻转）。**
   - 对整棵棋谱树做坐标变换：着手、摆子、标记和标签、保存的分析数据（LZ 候选点和变化）。
   - 变换后的局面按新坐标查分析缓存，不能把旧坐标的结果显示在新局面上。
   - 「水平」「垂直」分别指哪种翻转，照 Java 的实际效果。
   - 只支持正方形棋盘；非正方形返回类型化错误。
   - 一次变换是一步编辑：可以撤销和重做，文档变为未保存。
5. **设置。**
   - `always_on_top`：保存，由壳在启动时和修改时对主窗口生效。
   - 界面字号：Java 有小、中、大、其他四档。存成一个缩放比例（界面把它用到根字号），给出合理范围并校验。
   - `play_sound`：落子声开关。声音由界面播放；「同步时不播放落子声」随 P3 的在线同步再做。
   - 「加载棋谱中的贴目」：P2-11 已有 `read_komi`，确认菜单勾选用得上现有的读写命令即可。
   - 每项都有读写命令，照 P2 的约定：先原子保存再生效，失败时保留旧值。
6. **界面语言。**
   - `UiLanguage` 新增繁体中文、日语、韩语、泰语四项。
   - 「跟随系统」的映射：zh-TW、zh-HK、zh-Hant 对应繁体中文；其他中文对应简体；ja、ko、th 对应各自的语言；其余用英文。
   - Rust 返回给界面的文字（例如引擎目录的显示名），在新语言下有 Java 译文（`apps/desktop/src/locales/legacy/`）就用 Java 的，没有就用英文。
7. 新字段和新命令照约定：生成的 TS 里可选，mock 补默认值，mock 里是脚本化的 `command`；只读的查询用带默认值的 `query`。

## 不做

- 界面（P3-03）和四种语言的界面译文（P3-02）。
- 存档与读档、打开在线链接、同步时不播放落子声：后面的批次再做。

## 验收标准

1. 复制再粘贴得到同一盘棋（属性和分支一致）；剪贴板是非棋谱文字、为空时，各返回错误且不动当前棋谱；粘贴进来的局面能分析（fake-katago）。
2. 纯净棋谱、带评论的纯净棋谱、纯净分支，各有黄金样例测试；保存后当前文档的路径和保存状态不变。
3. PNG 写入：非 PNG 和超限的拒绝，原子写入有测试；复制图片到剪贴板经可替换的接口测试。
4. 四种变换各有测试；用 proptest 证明转四次等于原样、同一种翻转两次等于原样；保存的分析数据跟着变换；撤销后恢复原样；非正方形棋盘报错。
5. 新设置的默认值、读写和失败时保留旧值，各有测试；系统语言映射有测试。
6. 新依赖每个写一行理由；`docs/ARCHITECTURE.md` 更新。
