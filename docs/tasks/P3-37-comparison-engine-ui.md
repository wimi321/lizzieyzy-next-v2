## 目标

P3 第 10 批的界面，用 P3-36 的命令和事件。Java 参考：
- `gui/LizzieFrame.java`：
  - 3313–3351：进出双引擎模式；
  - 6604–6684：两块棋盘和下面的状态行。
- `gui/Menu.java`：
  - 1903–1914：双引擎模式菜单项；
  - 5471–5478、5601–5657、7025–7072、10060–10186：副引擎菜单和关闭引擎。
- `gui/BoardRenderer.java` 1515–1517、1775：第二块棋盘画副槽。

## 要做

1. **显示 → 布局模式 → 双引擎模式（Alt+6）**，照 P3-28 的预设规则：
   - **棋盘**：
     - 两块同样大小的方棋盘并排，左边是主引擎，右边是副引擎。
     - 隐藏小棋盘、评论、变化图和胜率图（同 Java）。
     - 窗口没有最大化时，宽度按 Java 改成棋盘区高度的两倍左右。
   - **状态行**，每块棋盘下面两行：
     - 左：「主引擎：名字　分析 开启 / 暂停　快捷键：空格」；「计算量：…　胜率：…」。
     - 右：「副引擎：名字」和状态（启动中、分析中、已暂停、失败及原因、未选择）；「计算量：…　胜率：…」。
   - **右边棋盘**：
     - 显示副引擎的候选点；Kata形势开着时显示副引擎的 ownership。
     - 悬停候选点显示变化，只画在悬停的那块棋盘上。
     - 点哪块棋盘都是落子。
     - 没选副引擎时，棋盘上提示「在「副引擎」菜单里选择对比引擎」；棋谱里有保存的 LZ2 时照样显示。
   - 退出双引擎布局回到进入前的布局（同其他预设）。
2. **菜单**
   - 双引擎布局时，菜单栏在主引擎菜单后多一个副引擎菜单（Java 的 `engineMenu2`）：
     - 标题「[n] 名字」，没选时「未加载引擎」；
     - 列出全部引擎，主引擎那一项不可选，当前副引擎打勾；
     - 分隔线，然后「重启当前引擎」「关闭当前引擎」。
   - 主引擎菜单里，副引擎那一项不可选。
   - 主引擎菜单的「关闭引擎」子菜单接上「关闭当前以外引擎」「关闭所有引擎」。
   - 功能搜索加「选择对比引擎」（同时能用「第二引擎」搜到）：
     - 不在双引擎布局时不可用，原因写「选择第二引擎前，请先启用对比模式。」（Java 的文案）；
     - 可用时打开副引擎菜单。
   - 换副引擎失败、同主引擎被拒时，显示原因。
3. **含 LZ2 的棋谱**：打开的棋谱 `has_comparison_analysis` 为真、又不在双引擎布局时，状态栏提示「此棋谱为双引擎分析棋谱，是否进入双引擎模式查看？」，带「进入」和关闭。不弹模态框；换棋谱后消失。
4. **文案**：中文、英文；其他语言照现有做法用英文占位。

## 验收标准

- Vitest：
  - 布局的进出和面板恢复；
  - 两块棋盘的状态行（各种状态、失败原因）；
  - 副引擎菜单的启用、勾选和不可选；
  - 关闭引擎的三项；
  - 功能搜索的可用和不可用；
  - LZ2 提示的出现、进入、关闭和换棋谱。
- Playwright：
  - 进入双引擎布局、选副引擎、两块棋盘有各自的候选点，带一张基线；
  - 副引擎启动失败；
  - LZ2 提示，进入后显示保存的副槽。
- `scripts/verify.sh --e2e` 通过；`check_budgets.py` 通过（基线截图注意 1 MB 上限，必要时只截一部分）。
- 真机：在这台 Mac 上配两个引擎（例如自带模型和另一个模型），进入双引擎布局跑一遍：
  - 换局面两边都跟着分析；
  - 暂停两边都停；
  - 关掉副引擎；
  - 截主窗口的窗口图。
