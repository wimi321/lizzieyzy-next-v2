## 目标

补上「显示」菜单里还没做的两项定为 MVP 的面板，并把 P2-08、P2-09 的后端接到界面上，P2 第 2、3 批就此做完。样式标准见 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **选点列表面板。** 「显示 → 面板 → 选点列表面板」，默认显示，开关保存在 P2-09 加的 `show_list_pane` 里。
   - 位置照 Java：右栏里和分支面板上下各占一半；分支面板隐藏时占满右栏。
   - 列照 Java：序号、坐标、胜率(%)、计算量、占比(%)、目差。胜率和目差跟「总是显示黑方胜率」「目数显示」一致。
   - 鼠标移到一行上，棋盘预览这个候选点的变化图，和移到棋盘上的候选点一样；双击一行落下这一手。
2. **超级鹰眼。** 「显示 → 面板 → 超级鹰眼」「分析 → 超级鹰眼」、顶部工具栏的「超级鹰眼(Y)」和 Y 键：打开评论面板的「问题手」页；评论面板隐藏时先显示它。
3. **文件。**
   - 打开、拖入 GIB 和带分析数据的 SGF 后，界面照常显示；候选点来自棋谱里存的数据时，状态栏或信息面板能看出来。
   - 从访达、资源管理器打开的棋谱和拖入的一样处理，失败时照拖入失败的提示。
   - P2-08 如果提供了「保存时带分析结果」之类的开关，放到 Java 对应的位置。
4. **缓存。** 「分析 → 清除分析信息（此手 / 全局）」「分析 → 清除 Lizzie 缓存（此手 / 全局）」，全局的先确认；「设置 → 综合设置」里加「启用缓存」。

## 验收标准

1. 每个新入口都有单元测试或 Playwright 测试：点了以后调用对应命令、界面随之变化。
2. Playwright 截图基线：选点列表面板（有候选点时）、超级鹰眼打开的问题手页。
3. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
