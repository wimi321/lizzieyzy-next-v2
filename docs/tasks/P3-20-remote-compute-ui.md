## 目标

把 P3-17 和 P3-18 的后端接到界面上。入口照 Java 版放；样式标准照 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **设置 → 远程算力**：一个窗口，两个页签，照 Java 的 RemoteComputeDialog。
   - **智子云算力**：
     - 登录：密码登录、验证码登录（提示「账号不存在时会自动注册」）、忘记密码；验证码按钮显示冷却倒计时；「记住登录」。
     - 登录后显示账号概览：VIP 状态和到期日、余额和昨日消费、连接数、最近一次用时和花费。还有「使用明细」「资金明细」（翻页），以及「充值」「开通 VIP」两个按钮，用系统浏览器打开官网。
     - 套餐和权重下拉框、「连接」。连接时显示进度。
     - 一句提示：断开连接不保证服务端立即停止计费。
   - **自建算力**：
     - 粘贴链接（自动规范化），或「从图片识别二维码」；「测试」显示版本或失败原因；「连接」。
     - 链接是 `ws://`（不加密）时，给出一句提醒。
   - 两个页签都有「切换到本地引擎」。
2. **设置 → 引擎里的 SSH 引擎**：
   - 在现有的引擎编辑表单里加一种「SSH 远程引擎」：主机、端口、用户、认证方式（密码或私钥文件，加口令）、远程命令。还有「测试」。
   - 首次连接或主机密钥变了时，显示指纹。
3. **状态**：
   - 主引擎是远程引擎时，引擎菜单和状态行写明远程类型。
   - 「远程引擎不支持」的功能入口变灰，并说明原因。
4. **打开在线链接的预填**（P3-19 留下的）：对话框打开时调用 P3-22 的 `clipboard_link()`，有链接就预先填进去（`OpenUrlDialog` 已有 `initial`）。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后调用对应的命令，界面随事件变化。
2. Playwright 截图基线：
   - 智子登录页、智子账号概览、自建算力页；
   - SSH 引擎表单；
   - 主机密钥变化的提示。
3. 每个 Playwright 测试最多点开两层菜单，本地 1.3 秒以内（Linux CI 的 5 秒上限）。
4. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
