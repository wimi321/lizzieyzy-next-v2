## 目标

棋盘照 Java 版 `BoardRenderer` 严格还原：japanese 风格、default 主题，以及维护者自己的设置。参照物和统一规则见 P1-40。界面由 Claude 做。

参照物是维护者装的 next-2026-10-21.1。此后维护者在 LizzieYzy Next 里改过的地方，照新版做：
- 棋盘下方的名字不要浅色底板。10-22 去掉了：用户嫌刺眼，底板还挡住一线的棋子。
- 空棋盘提示不盖住引擎对空棋盘的分析。11-02 改的。

## 要做

1. **棋盘和棋子：**
   - 尺寸照 `setupSizeParameters`：有坐标或名字时边距 5.5%，格距取整数像素，棋子半径为半格减一；
   - 贴图：`board.png` 平铺，棋子用 `black0.png`、`white0.png`；
   - 棋盘的光照渐变和内阴影（`GlassEffectRenderer`），棋子的阴影（`drawShadowCache`）和高光；
   - 网格线：边线和内线的粗细照 Java 的公式，星位照 `BoardStylePainter`；
   - 四边坐标的字体、大小、位置照 Java。棋盘下方显示名字时，下边不画坐标。
2. **最后一手：** 维护者的设置不显示手数，最后一手画落子评价标记：
   - 这一手和上一手都有分析时，按这一手的得失等级填色：最佳、好、一般、缓手、问题手、恶手，颜色照 `MoveRankDefinition`；
   - 外加一个黑白反色的圆圈；没有分析时只画圆圈；
   - 停一手：棋盘中央画半透明圆和「停一手」。
3. **候选点**照 `drawLeelazSuggestions`：
   - 最多 10 个，照维护者设置的 `limit-max-suggestion`；
   - 颜色：最佳点青色带蓝圈；其余按计算量占比在红绿之间取色（不是按胜率差），透明度也随占比变；圆下先铺一层棋盘贴图，盖住网格线；
   - 圆里三行：胜率、计算量、目差。胜率和目差用 Java 自带的 Open Sans Semibold（Apache-2.0，许可证由 P1-44 放进安装包）；
   - 前 9 个候选点的右上角画橙底序号；
   - 棋谱里的下一手画虚线圈；下一手不在候选点里时，照 `drawNextMoveBlunder` 在那里画出走这一手之后的胜率和目差。
4. **鼠标悬停候选点时的变化图**照 `VariationPreviewGenerator`：
   - 变化里的棋子带序号，最后一手画红色小三角；
   - 被提掉的子画成半透明；
   - 悬停的候选点画红圈，保留它的三行数字；
   - 悬停处有一圈白色光晕。
5. **Kata形势**照 `drawKataEstimateByTransparent` 的默认样式：黑方小方块、白方稍大的方块，深浅随归属程度变，画在棋子上面。
6. **棋盘下方的名字**照 `BoardNamePlate`，不要底板：中间两枚小棋子，轮到谁走谁在上面；左边黑方名字黑字，右边白方名字白字黑边。
7. **空棋盘提示**照 `EmptyBoardHint`：棋局为空、且这一手还没有分析时，棋盘中央显示「打开棋谱、把 SGF 拖进来，或新建对局」。

## 不做

- 手数、落子评价标记数量等其他显示选项：以后做「显示」菜单时再接。
- 把棋谱拖进窗口打开：后端在 P1-44 做。

## 验收标准

1. 同样的窗口大小下，与 Java 版截图逐一对照：布局和信息一致，观感不差于 Java 版（2026-11-11 维护者放宽，原为「看不出差别」）：
   - 空棋盘，带候选点；
   - 中盘（参照棋谱第 60 手）；
   - Kata形势；
   - 悬停候选点时的变化图。
2. Vitest 覆盖尺寸公式、候选点配色和文字大小的计算；Playwright 通过，截图基线重新生成。
