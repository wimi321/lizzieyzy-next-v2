## 目标

把 P3-27 的布局设置接到主窗口。入口照 Java 版放（行为要点写在本卡和 P3-27 里）；样式标准照 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **布局模式**（显示 → 布局模式；Alt+1 至 Alt+5）
   - 默认模式（Alt+1）：`Normal`；打开小棋盘、选点列表、胜率图、评论、信息、分支面板；关掉两个放大；窗口改成 Java 的比例：宽 = (高 − 工具栏) × 165%。
   - 经典模式（Alt+2）：`Normal` 的预设：关状态栏、分支面板、评论；开小棋盘、胜率图、信息；开放大小棋盘；宽 × 145%。
   - 精简模式（Alt+3）：`Min`；只剩棋盘，不画状态栏；窗口接近正方形：宽 0.94 × min(宽, 高 − 工具栏)、高 min + 工具栏。打开任何面板就回到 `Normal`。
   - 思考模式（Alt+4，勾选项）：`Thinking`；左边一块大棋盘，边长 min(宽, 高)，只画当前局面（不画候选点、下一手提示和名字），点它照常落子；带分析的主棋盘缩小放在右边剩下的区域，其余面板照 Java 排在中间；宽 × 166%。
   - 四方图模式（Alt+5，勾选项）：`MultiView`；左上 2×2 四块小棋盘，分别显示第 1 至第 4 选点的变化（用现有的变化预览命令）；主棋盘放在剩下的区域；宽 × 162%。
   - 双引擎模式（Alt+6）仍然变灰，随对比引擎那一批。
   - 勾选项再点一次回到默认模式（Java 只会重新套用一次）。
   - 改窗口大小统一走 `fit_main_window`：窗口最大化时不改。
2. **放大小棋盘（Ctrl+F）和放大胜率图（Ctrl+W）**（显示 → 主界面设置，勾选项，互斥）
   - 布局照 Java（`gui/LizzieFrame.java` 7254–7326）：主棋盘靠右。
     - 放大小棋盘：左边从上到下是信息和统计（分支面板在它们右边）、胜率图、小棋盘（取宽高中小的一边，居中）；选点列表放在胜率图右半边。
     - 放大胜率图：左上四分之一高是小棋盘和分支面板，下面是信息、统计，胜率图填到底。
   - 放大小棋盘时，小棋盘没开就先打开。放大胜率图时不隐藏小棋盘（Java 会隐藏，不照搬）。
   - 竖屏（宽 < 高）时两个放大不生效，勾选保持不变。
   - macOS 上 ⌘W 是关窗口：Ctrl+W 在 macOS 只认 Control 键。Ctrl+F 两种都认。
3. **主棋盘/界面位置**（显示 → 主棋盘/界面位置 → 左移 `[` / 右移 `]`）：`board_position` 加减 1，0–8，默认 4；`Normal` 横屏下主棋盘的横向位置照 Java 的公式。两个放大和思考、四方图不用它。
4. **面板菜单**
   - 恢复默认面板尺寸：`board_position` 回 4。
   - 重置界面位置（显示 → 重置界面位置）：调 `reset_window_positions`，立即生效，不提示重启。
5. **可视化面板设置**（显示 → 面板 → 可视化面板设置）
   - 一个窗口，照 Java 的 `SetCustomMode`：7 个面板开关、放大小棋盘、放大胜率图、位置滑块 0–8。浮动主棋盘和浮动小棋盘两项在 P3-29 加。
   - 每项改动立即在主窗口预览；联动：两个放大互斥，任一放大时滑块变灰。
   - 「应用」保存；「取消」、Esc 或关闭还原成打开窗口时的样子。
6. **自定义布局 1、2**（显示 → 自定义布局 1 (Alt+8) / 2 (Alt+9)，菜单项旁有「设置」）
   - 「设置」打开同一个窗口，标题「设置自定义布局 N」，先套用这个槽已有的布局；「应用」把当前样子存进槽，包括布局模式和主窗口位置（最大化与否）。
   - 选菜单项或按快捷键：套用这个槽，走完整的模式切换；主窗口位置经过 P3-27 的屏幕检查。
   - 没存过的槽：菜单项打开「设置」。
7. **快捷键**：Alt+1 至 Alt+5、Alt+8、Alt+9、Ctrl+F、Ctrl+W、`[`、`]`；照现有规则，焦点在文本框里或有对话框时不生效。macOS 上 Option+数字按物理键识别。

## 验收标准

1. 每个入口都有单元测试或 Playwright 测试：点了以后调用对应的命令，界面随返回的设置变化。
2. `layout.ts` 的新布局有单元测试：各模式、两个放大、位置 0 / 4 / 8、竖屏忽略放大、区域互不重叠且都在面板内。
3. Playwright 截图基线：思考模式、四方图模式、精简模式、放大小棋盘、放大胜率图、可视化面板设置窗口。
4. 每个 Playwright 测试最多点开两层菜单，本地 1.3 秒以内。
5. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
