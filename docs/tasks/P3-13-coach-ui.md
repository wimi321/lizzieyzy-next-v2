## 目标

把 P3-12 的后端接到界面上。入口照 Java 版放；样式标准照 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **入口**：菜单栏右侧的「AI 陪练」按钮和「棋局 → 新对局 → AI 陪练」。
   - 按钮文字随状态变化：AI 陪练、准备中…、陪练中。
   - 陪练中点按钮，重新打开陪练面板。
2. **准备对话框。**
   - 选项：
     - 对手棋力：滑块加 −/+，20 级到 9 段；
     - 训练方式：三种，各有一句说明；
     - 执棋：黑、白、随机；
     - AI 思考节奏：自然、快、慢；
     - 更多设置：让子、从当前局面开始。贴目只显示，不能改。
   - 模型状态：
     - 正在检查；
     - 已就绪，显示大小；
     - 需要下载（约 99 MB）：按钮为「下载并开始」，对话框里显示进度、暂停和取消，下载完自动开始；
     - 损坏；
     - 也可以导入本地文件。
   - 开始时如果要重启主引擎，显示进度。版本过低或 TensorRT 时显示原因。
3. **陪练面板**：放在 Java 放的位置，即主窗口右侧的面板区。
   - 标题：「3段 AI · 执白 · 像3段棋手一样下」。
   - 状态：轮到你、AI 思考中、等你决定、对局结束。
   - 双方提子数和用时，以及贴目。
   - 胜率曲线：
     - 边下边提醒：段位胜率，注明「按 3段 水平估算」；
     - 边下边分析：引擎的胜率；
     - 实战后复盘：不显示。
   - 上一手的卡片：手数和坐标、胜率变化、约亏几目、等级和一句说明。
   - 边下边提醒时，显示各等级的计数和最近 8 手的评价。
   - 按钮：
     - 提示（H）：两步，第一步标出区域，第二步标出准确的点；
     - 悔棋；
     - 停一手（P）；
     - 认输：要确认；
     - 结束对局：要确认。
4. **恶手卡片**：显示等级、胜率变化和亏的目数，三个按钮：重下这手、看 AI 推荐、不重下，继续对局。
5. **赛后总结**：
   - 你赢了、你输了或和棋，以及结果；
   - 手数、关键失误、提示次数、悔棋次数；
   - 值得复盘的 3 手：点一下就跳到那一手之前的局面；
   - 「开始复盘」和「再来一盘」。
6. 不显示实时分析的训练方式下，候选点、热点、形势和胜率图都隐藏；空格和 H 给出「分析已隐藏」的提示。

## 验收标准

1. 每个入口和按钮都有单元测试或 Playwright 测试：调用对应的命令，界面随事件变化。
2. Playwright 截图基线：
   - 准备对话框：模型就绪、需要下载、下载中三种；
   - 陪练面板：边下边提醒；
   - 恶手卡片；
   - 提示的两步；
   - 赛后总结。
3. 每个 Playwright 测试最多点开两层菜单，本地 1.3 秒以内（Linux CI 的 5 秒上限）。
4. `scripts/verify.sh --e2e` 通过，`check_budgets.py` 通过。
