## 目标

P3 第 9 批的界面，用 P3-32 的服务、消息和命令。Java 参考：`src/main/resources/web/`（`index.html`、`board.js`、`board.css`）、`gui/Menu.java` 4054–4122、`gui/BottomToolbar.java` 1132–1178。

## 要做

1. **浏览器里的旁观页**（Vite 的第二个入口 `web.html`，打包进前端资源，由 P3-32 的服务提供）
   - 用桌面版同一套棋盘绘制：棋子、最后一手、候选点（首选青色，其余按访问占比着色；每个显示胜率、访问数、目差，三行可以分别开关）、悬停或长按 500 ms 显示变化、有 ownership 时的形势图。
   - 状态行：手数、轮走方、黑方胜率、目差、总访问数、贴目和规则。
   - 胜率图和目差图，悬停显示该手的数值；问题手列表（Java 的 5% 门槛换成新版的问题手查询结果）。
   - 网页自己的设置存在浏览器的 localStorage：坐标样式（无、标准、带 I、野狐）、黑白视角。
   - 试下：
     - 「试下」按钮；
     - 自己试下时有后退、前进、回到起点、退出，以及可点的分支编号；
     - 别人试下时显示「有人正在试下」；
     - 被拒、落子不合法时显示原因，不弹浏览器的 alert。
   - 断线时盖一层「连接中断，正在重连」，按 1 秒到 30 秒退避重连，带上服务端给的重连凭据。
   - 适配手机竖屏：棋盘在上，其余在下。
   - 文字跟随浏览器语言（中文、英文），其他语言用英文。
   - 不能引用 Tauri 的 API 和桌面版的 mock，用 ESLint 的 `no-restricted-imports` 对网页的目录强制。
2. **主窗口**
   - 同步菜单下的「网页旁观」：
     - 开启 / 关闭；
     - 复制访问地址；
     - 允许旁观者试下（勾选）；
     - 强制结束试下（有试下时可用）。
     - 这些都进功能搜索。
   - 开启后：
     - 状态栏显示「网页旁观 · N 人」，点它打开一个小窗，列出访问地址（主地址在前，其余在下，各自可以复制）、人数、谁在试下以及「强制结束试下」；
     - 第一次开启时提示 Windows 可能弹出防火墙询问，要允许局域网访问。
   - 开启失败（端口都被占用）时显示原因。
   - 旁观者试下时，主窗口显示试下的局面（新版现有的试下样式），顶部提示「网页旁观者正在试下」和「结束试下」按钮。
3. 中文、英文文案；其他语言用英文占位，照现有的做法。

## 不做

- 后端（P3-32）。
- 二维码。以后有需要再加，需要新依赖。

## 验收标准

- Vitest：
  - 网页的消息处理：全部状态、分析更新、试下状态各种情况、被拒、重连；
  - 坐标样式和视角；
  - 主窗口的菜单状态、状态栏和小窗、强制结束、开启失败。
- Playwright：
  - 主窗口：开启、小窗、强制结束，各一条，带一张基线；
  - 网页：用一个测试里的假 WebSocket 服务（只在测试里）跑一遍，看全部状态、悬停变化、试下、断线遮罩，带两张基线（桌面宽度、手机竖屏）。
- `scripts/verify.sh --e2e` 通过；`check_budgets.py` 通过。
- 真机：在这台 Mac 上开启，用同一局域网的另一台设备（Windows 测试机的浏览器或手机）打开地址，看到棋局和分析、试一手、强制结束，截主窗口的窗口图。
