## 目标

左栏照 Java 版严格还原。参照物和统一规则见 P1-40。界面由 Claude 做。

如果缺后端数据（例如 KataGo 的目差不确定度），先在卡里补一段后端要求，交给 Codex，再接界面。

## 要做

1. **提子框：**
   - 黑白棋子图；
   - 规则名，例如「中国规则」；
   - 轮到谁走：「● 黑走」；
   - 「提子 n　贴目 x　提子 n」。
2. **胜率条：**
   - 「黑 x%　手数　白 x%」；
   - 黑白条；
   - 下面一行「白领先 x 目」。
3. **胜率图**照 `WinrateGraph`：
   - 底色、虚线网格；
   - 纵轴 100 / 50% / 0；
   - 蓝色胜率线，线宽 1.7；
   - 紫色目差线；
   - 图例「黑方胜率」「目差」；
   - 横轴手数；
   - 当前手；
   - 点击和拖动跳转。
4. **评论 / 问题手面板**照 `SidebarPanel`：
   - 两个标签；
   - 右侧状态，例如「● 评估完成」；
   - 评论区的分析文字格式照 Java 版：「白棋 胜率: … / 领先: … 不确定度: … / (引擎 / n 计算量) / 贴目: …」；
   - 问题手列表照 `BlunderListPanel`。
5. **状态栏：** 「引擎名 · 分析…」。

## 验收标准

1. 与 Java 版截图逐块对照，看不出差别：
   - 开局；
   - 打开整盘棋谱并完成自动分析后。
2. Vitest、Playwright 通过，截图基线重新生成。
