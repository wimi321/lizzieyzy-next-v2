## 目标

把 P2-01 的编辑命令接到界面上。入口照 Java 版放：菜单项、工具栏按钮和快捷键都在原位，原来置灰的点亮。样式由 Claude 定，标准见 ROADMAP 2026-11-11 的记录：布局和信息与 Java 版一致，观感不差于它。

## 要做

1. **评论编辑。** Java 版：点评论区进入编辑，点别处结束并保存。
   - 在「评论」标签里点评论区，评论变成文本框，内容是这一手的棋谱评论；分析摘要不进文本框。
   - 点别处或按 Ctrl+Enter 保存；按 Esc 放弃。内容没变就不发命令。
   - 编辑时键盘只归文本框：方向键、空格这些快捷键不翻手，不暂停分析。
   - 正在编辑时自己翻手（滚轮、点变化树、点胜率图），先保存，再翻；
   - 正在编辑时棋局被别处换掉（打开别的棋谱、棋盘同步），没保存的文字作废，不写到别的手上。
2. **删除和撤销：**
   - 「编辑 → 删除一手」（Delete）和底部工具栏的「删除」：删掉当前手和它后面的棋，回到上一手；
   - 「编辑 → 删除分支」（Shift+Delete）；
   - 「编辑 → 撤销删除」「恢复删除」：撤销、重做上一次编辑。后端的撤销不只管删除，下新的一手、改评论、改棋局信息也算，菜单文字照实改成「撤销编辑」「恢复编辑」，位置不变；
   - 在根节点时，两个删除置灰。
3. **设为主分支：** 「编辑 → 设为主分支」（L）和底部工具栏的按钮。当前手已经在主线上时置灰。
4. **新棋盘：**
   - 四个入口做同一件事：「文件 → 新建」、顶部工具栏第一个图标、「编辑 → 清空棋盘」（Ctrl+Home）、底部工具栏的「清空棋盘」。开一盘空棋，棋盘大小、贴目、规则沿用当前这盘；
   - 先问「此操作将会清空棋盘和所有分析,是否继续?」。「显示 → 主界面设置 → 显示清空棋盘提示对话框」决定问不问；
   - 「编辑 → 设置棋盘大小」（Ctrl+I）：19x19、15x15、13x13、9x9、其他（宽 x 高）。确定后开一盘这个大小的空棋，同样先问。
5. **棋局信息：**
   - 「编辑 → 编辑棋局信息」（I）打开对话框：双方名字和段位、贴目、规则、结果、日期、赛事；
   - 顶部工具栏的「贴目」可以直接改。
6. **保存：**
   - 「文件 → 保存」（Ctrl+S）和工具栏的保存图标：棋谱有文件路径时写回原文件，先问「覆盖原文件?」，「显示覆盖文件提示对话框」决定问不问；没有路径时和「另存为」一样，先选位置；
   - 「另存为」总是先选位置；
   - 保存以后，标题里的文件名跟着变。
7. **最近打开：** 「文件 → 最近打开」列出最近的棋谱，显示文件名，悬停显示完整路径，点一个就打开。列表为空时放一条置灰的说明。末尾一项「清空列表」。
8. **变化树：** 有评论的节点加标记；评论变了，标记跟着变。

两个「显示…提示对话框」开关这一批只在本次运行内有效。存进设置的事，随第 2 批「显示」菜单的设置一起做。

## 不做

- 摆子、起始局面、标记、试下、棋盘右键菜单：后面的卡。
- 退出或换棋谱之前提示保存：Java 版没有，以后看需要再说。

## 验收标准

1. 上面每一项都有 Playwright 用例：从菜单、工具栏或快捷键触发，核对发给后端的命令和参数。每个新对话框有一张截图基线。
2. Vitest 覆盖：
   - 评论编辑的保存、放弃、翻手前保存、棋局被换掉时作废；
   - 保存走哪条路：有路径、没有路径、关掉提示；
   - 「最近打开」菜单的生成。
3. `scripts/verify.sh` 通过，截图基线重新生成。
